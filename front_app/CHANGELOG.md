# 更新日志

本文档记录 Research Life 的重要更新概况。每次更新按时间倒序追加，重点说明本次变更的目标、范围和影响。

## 2026-05-15

### 实现：周分析接入本地大模型协调层

- 新增分析协调层，周分析会在启用本地 LLM 时优先调用 Ollama，失败后按设置决定是否回退到规则分析。
- 新增可替换的大模型 provider 接口、本地 Ollama provider 和远程服务器 provider 骨架，为后续远程模型接入预留扩展点。
- 将周分析入口改为异步流程，修正开始分析、重新分析、示例分析和导入后自动分析的等待逻辑。
- 加强大模型安全提示词，明确周记文本只是待分析数据，不允许通过文本指令改变输出格式、执行命令、访问文件或控制应用。
- 增加 20000 字 LLM 输入上限，超限时不发送给模型，直接使用规则分析并提示。
- 补充协调层、本地 LLM 服务、远程 provider 和控制器启用路径测试。

### 规划：周分析接入本地与远程大模型

- 明确周分析能力升级方向：优先接入本地 Ollama 大模型分析，保留现有规则分析作为兜底。
- 规划新增分析协调层，统一调度规则分析、本地大模型分析，并预留后续远程服务器大模型接入扩展点。
- 明确安全边界：周分析模型调用只接收用户周记文本和结构化分析指令，不允许模型触发本地命令、文件操作、网络请求或系统控制行为。
- 要求对大模型输出进行 JSON schema 约束、字段校验、枚举限制、置信度范围检查和相关任务索引越界检查。
- 规划失败处理策略：本地模型不可用、超时、HTTP 错误、输出格式非法或校验失败时，根据用户设置决定是否回退到规则分析。
- 确认后续实现应保持现有确认结果、历史记录、日历同步和人物关系同步流程不变，仅替换分析草稿生成来源。
