# 工作台全局导航与 AI 助手收尾设计

**日期：** 2026-08-16

**状态：** 已确认

**范围：** `feature/local-runtime` 中 2026-08-12 遗留的未提交 Flutter 工作台改动

## 1. 目标与边界

以当前未提交代码代表的新信息架构为准，完成代码、测试、文档和构建验证的收尾：

- 天气、AI 助手和日历是全局侧栏中的独立目的地。
- “今日”不再分成今天、日历和待办三个页签，而是在一个页面中整合今日安排与待办。
- “科研”保留概览、文献、笔记和统计；周分析与人物转入“生活”。
- AI 助手作为工作台内容嵌入，保留本地会话历史和可展开的生成过程。

本轮不新增 AI 供应商、联网搜索、文件上传、RAG、云同步或新的视觉重构。不删除与任务无关的用户文件，不将 `.qa/`、`.run_logs/`、构建产物或本地截图纳入提交。

## 2. 导航模型

`WorkbenchNavigationController` 继续持有工作区与各工作区的最后选中页签，同时持有天气、日历和 AI 三个独立目的地的打开状态。

三个独立目的地与普通工作区互斥：

1. 打开天气、日历或 AI 时，关闭另外两个独立目的地。
2. 选择任意工作区或工作区页签时，关闭所有独立目的地。
3. 切换后不重建已访问内容，使页面内的筛选、滚动、输入和 AI 历史保持不变。
4. 工作区页签映射为：
   - 今日：今日概览。
   - 科研：概览、文献、笔记、统计。
   - 资料：资料库、PDF 工具。
   - 生活：校园、周分析、人物。
   - 设置：设置概览。

## 3. 页面组成

### 3.1 今日

今日页在同一工作区内展示时间线和待办。待办按未完成与已完成分组；未完成项再区分今天和接下来，并按优先级后时间排序。页面直接提供完成切换、优先级设置和快速记录；已完成列表默认折叠。

### 3.2 科研与生活

科研页不再提供页内 AI 入口，也不再承载周分析和人物。科研概览中指向周分析的操作改为跨工作区导航到生活的周分析页签。生活工作区以校园、周分析和人物三个页签统一承载与校园生活、周复盘和人际记录有关的功能。

### 3.3 AI 助手

AI 页使用嵌入模式，不显示全屏对话框的返回按钮。历史栏展开时保持现有宽度，收起时缩为独立的小型操作区，不与工作台主侧栏视觉粘连。

用户消息可附带一条结构化的本地生成过程，状态只有 `active`、`completed`、`failed` 和 `stopped`。界面默认展开正在进行的过程，完成、失败或停止后可由用户展开回看。不展示供应商的内部 reasoning 原文。

## 4. 数据流与容错

AI 生成过程使用带 `kind` 和版本的 JSON 编码，存入已有消息的 `reasoningContent` 字段，不新增数据库表或迁移。解析遇到空值、非本应用数据、未知状态或非法 JSON 时返回“无可展示过程”，不影响消息内容。

过程写入失败时，控制器可在内存中更新界面，但不得因此丢失用户消息、助手回复或重试能力。取消网络请求写入 `stopped`，正常失败写入 `failed`，成功持久化助手回复后写入 `completed`。不记录 API Key、Authorization header 或用户对话正文。

## 5. 测试与验收

先以当前未提交的导航、工作区、AI 控制器和 AI 页面测试为行为基线，在修复时保持红—绿节奏。最终验收包括：

1. 目标测试覆盖独立目的地互斥、工作区页签归属、今日待办操作、AI 嵌入布局和生成过程的成功/失败/取消状态。
2. `dart format` 不产生额外差异。
3. 完整 `flutter test` 通过。
4. `dart analyze` 无新增 warning 或 error；已知 info 必须明确报告。
5. Windows Debug 构建通过。
6. 若本机环境允许，手动检查侧栏切换、AI 历史收起/展开、日历打开、今日待办操作以及窄窗口布局。

测试通过不代表自动提交所有工作树内容。收尾提交只包含与本规格相关的源码、测试和文档；未跟踪的 QA 发布包和运行日志继续保留在本地但不入库。
