# 《研究生活》普通用户使用文档

本文面向第一次使用软件的普通用户，重点说明每个页面能做什么，以及最常用的操作流程。

## 1. 软件是做什么的

《研究生活》是一个 Windows 桌面应用，用来集中管理研究生日常中的几类信息：

- 每周记录与事项分析：把周记、总结、计划自动拆成事项和人物关系。
- 待办中心：汇集周分析产生的计划与手动添加的计划，勾选完成、设置优先级。
- 统计仪表盘：查看阅读热力图、阅读时长趋势、事项分类、人物排行和待办完成情况。
- 全局搜索：跨文献、事项、人物、会话和地点快速查找。
- 日历提醒：当天有计划时右下角弹出毛玻璃提醒卡片。
- 日程与待办上云：登录后，手动添加的计划、勾选完成和优先级会自动同步到云端，换设备自动拉回。
- 独立 Markdown 笔记：在「我的笔记」新建/编辑/删除 Markdown 随笔，登录后自动同步到云端。
- 到点提醒：日历计划可设置具体时间，到点前 5 分钟在右下角弹出提醒；没设时间的计划当天提醒。
- 快速捕获：任意界面按 Ctrl+Shift+C 随手记一句话（记录/计划/笔记）。
- 锁屏 PIN：设置后，长时间未操作（5 分钟）或重启软件需要输入 PIN 解锁。
- 周分析会话上云：确认的周分析会随登录自动同步到云端，换设备自动拉回。
- 日历与周报：在日历里查看记录、手动补充事项，并生成周报提示词。
- PDF 阅读：导入本地 PDF，阅读、检索、标注和做笔记。
- 校园地图：在校区地图上添加自己的地点标记、备注和收藏。
- 人物关系：从周分析中整理人物和关联事项。
- 历史记录：回看、编辑或删除已保存的周分析与校历导入。
- 设置与桌宠：调整主题、天气、图片、数据备份、本地 AI 和桌宠。

## 2. 第一次使用建议

如果你拿到的是打包好的 Windows 版本，请先解压整个文件夹，再双击 `research_life.exe`。不要只单独复制或移动这个 exe，因为同目录下的 `data` 文件夹和 DLL 也是运行所需文件。

1. 启动软件后，先看左侧导航栏。主要页面包括：首页、日历、待办、统计、校园地图、阅读、周分析、人物关系、历史、设置。
2. 进入「设置」，确认主题、毛玻璃效果、桌宠、文件位置和主页图片是否符合自己的习惯。
3. 回到「首页」，点击右上角天气区域，可以选择城市或刷新天气。
4. 进入「周分析」，粘贴一段本周记录，点击「开始分析」，确认结果后，日历、人物关系和历史记录会自动同步。

## 4. 各页面怎么用

### 4.1 首页

首页显示当前时间、公历日期、农历日期和天气信息。右上角天气卡片可以刷新天气，也可以搜索并切换城市。

如果启用了桌宠，桌宠会作为软件内浮层出现，并在启动后提醒当天任务。

### 4.2 日历

日历页用于按日期查看所有记录。记录来源包括周分析结果、手动添加事项、导入的校历、节假日和 PDF 阅读记录。

常用操作：

- 切换月份：使用「上个月」「下个月」「本月」。
- 查看某天记录：点击日历中的日期。
- 添加记录：选中某一天后，点击「添加记录」，填写标题、分类和类型。
- 编辑记录：选中某一天后，点击可编辑记录旁的编辑按钮。
- 生成周报提示词：先点击起始日期，再点击截止日期，点击「生成周报」，复制提示词后粘贴到其他 AI 工具中生成周报。
- 修改周报模板：生成周报弹窗里可以编辑「常用模板」，保存后之后会默认使用新模板。

注意：节假日和校历记录是锁定内容，不能在日历页直接修改。校历需要从「设置」或「历史」里重新导入或编辑。

### 4.3 校园地图

校园地图支持「未来城校区」和「南望山校区」。可以拖动、缩放地图，也可以新增自己的地点标记。

常用操作：

- 切换校区：使用顶部「校区」下拉框。
- 查找地点：在「搜索自定义地点」输入地点名称或备注关键词。
- 筛选地点：点击「筛选」，按分类查看；也可以勾选「只看收藏」。
- 缩放地图：使用放大、缩小按钮，或触控板缩放。
- 新增标记：点击「新增标记」，再点击地图落点，填写地点名称、分类、备注、图标和颜色，最后保存。
- 管理标记：点击地图上的标记，可以编辑、收藏或删除地点。
- 显示控制：可以隐藏或显示标记，也可以「重置视图」回到默认位置。

地点分类包括学习、吃饭、宿舍、实验、运动、社交、办事和其他。

### 4.4 阅读

阅读页用于管理和阅读本地 PDF。导入后的文件会出现在左侧文库中，软件会记住上次阅读页码。

常用操作：

- 导入 PDF：点击「导入 PDF」，或把 PDF 文件拖到阅读页。
- 选择分类：导入前可选择未分类、论文、课程、项目、书籍或资料。
- 阅读控制：支持上一页、下一页、缩小、放大、搜索、添加书签和全屏阅读。
- 查看侧栏：侧栏包含文库、缩略图和标注。
- 标注文选：选中 PDF 中的文字后，可以添加高亮、下划线、删除线、波浪线、复制文本或做笔记。
- 管理标注：在「标注」侧栏里按全部、高亮、笔记、书签筛选，也可以编辑笔记或删除标注。

阅读时间达到一定长度后，软件会自动生成一条阅读记录，并同步到日历中。

### 4.5 周分析

周分析页是把自然语言周记整理成结构化事项的入口。可以直接粘贴文本，也可以导入 TXT、Markdown 或 Word `.docx` 文件。

常用操作：

- 输入记录：在文本框中粘贴本周记录。
- 导入文件：点击「导入文件」，或拖入一个 TXT、MD、DOCX 文件。
- 开始分析：点击「开始分析」，软件会生成总结、已完成事项、待执行计划和人物关系。
- 确认结果：检查右侧结果后点击「确认结果」，保存后会同步到日历、人物关系和历史记录。
- 重新分析：结果不满意时点击「重新分析」。
- 清空或重置：可以清空输入，也可以重置当前草稿。
- 编辑旧记录：从「历史」点击编辑后，会回到周分析页修改原记录，保存后覆盖原记录。

如果在设置中启用了本地 LLM 周分析，软件会优先调用本机 Ollama 模型；如果模型不可用，会按设置回退到规则分析。

### 4.6 人物关系

人物关系页会根据已确认的周分析记录生成关系图谱。中心节点是「我」，周围节点是识别出的人物。

常用操作：

- 查看关联事项：点击人物节点，查看与该人物有关的待办和记录。
- 查看全部事项：在人物详情卡片中查看该人物的全部关联事项。
- 编辑称谓：把人物名称改成更习惯的称呼，并可保留旧称谓作为别名。
- 合并人物：如果同一个人被识别成多个名称，可以合并为一个人物。

如果页面为空，先到「周分析」完成一次分析并确认结果。

### 4.7 历史

历史页保存已确认的周分析上传记录和校历导入记录。

常用操作：

- 查看记录摘要：按保存时间倒序查看每次分析或导入的摘要。
- 编辑周分析：点击周分析记录的编辑按钮，回到「周分析」页修改。
- 编辑校历：点击校历记录的编辑按钮，回到「设置」里的校历导入区修改。
- 删除记录：删除周分析会同步移除相关人物、事项和规划；删除校历会同步移除对应校历事件。

### 4.8 设置

设置页采用搜索、分类和目录结构。可以在顶部搜索框输入关键词，例如「路径」「校历」「Ollama」「图片」。

主要设置项：

- 颜色主题：切换软件整体配色，选择后自动保存。
- 本地 LLM 周分析：配置 Ollama 地址、模型、超时时间、规则兜底和 JSON 校验，并可测试连接。
- 桌宠：添加桌宠、选择当前桌宠、启动或停止桌宠、发送测试消息，并设置是否随软件启动或退出。
- 文件位置：打开应用数据目录、数据库目录、主页图片目录；也可以备份数据库或导出咨询包。
- 主页图片：更换研究墙和生活墙图片，或刷新图片。
- 校历导入：粘贴标准格式的校历文本，导入后会出现在日历中；也提供给外部识别软件使用的提示词和输出模板。

## 5. 常用流程

### 5.1 记录一周并生成结构化结果

1. 打开「周分析」。
2. 粘贴本周记录，或导入 TXT、MD、DOCX 文件。
3. 点击「开始分析」。
4. 检查生成的事项、人物和提醒。
5. 点击「确认结果」。
6. 到「日历」「人物关系」「历史」查看同步后的内容。

### 5.2 生成周报提示词

1. 打开「日历」。
2. 点击周报起始日期。
3. 再点击周报截止日期。
4. 点击「生成周报」。
5. 在弹窗中检查提示词，点击「复制提示词」。
6. 把提示词粘贴到其他 AI 工具中生成周报。

### 5.3 手动补一条日程或记录

1. 打开「日历」。
2. 点击要添加记录的日期。
3. 点击「添加记录」。
4. 填写标题，选择分类和类型。
5. 点击「添加」。

### 5.4 导入校历

1. 打开「设置」。
2. 找到「校历导入」。
3. 可以先复制页面提供的「给外部识别软件的提示词」，让外部工具把校历整理成标准文本。
4. 把标准文本粘贴到输入框。
5. 点击「导入校历」。
6. 回到「日历」查看校历事件。

校历文本格式是每行一个事件：

```text
开始日期 | 结束日期 | 事件标题 | 分类 | 类型
```

分类只支持 `study`、`work`、`life`、`health`、`social`、`other`。类型只支持 `plan` 和 `record`。

### 5.5 阅读并标注 PDF

1. 打开「阅读」。
2. 选择分类，点击「导入 PDF」。
3. 从左侧文库选择 PDF。
4. 阅读时选中文字，使用高亮、下划线、删除线、波浪线或笔记。
5. 在「标注」侧栏统一查看和管理标注。

### 5.6 备份或迁移数据

1. 打开「设置」。
2. 找到「文件位置」。
3. 点击「备份数据库」生成数据库备份。
4. 需要迁移到其他电脑时，先关闭软件，再复制应用数据目录。

默认应用数据目录是：

```text
D:\桌面\研究生活\.research_life
```

如果使用了 PDF 阅读库，也建议一并复制：

```text
D:\桌面\研究生活\资料
```

## 6. 支持的导入文件

周分析支持：

- `.txt`
- `.md`
- `.docx`

暂不支持：

- `.doc`
- `.xls`
- `.xlsx`

阅读页支持：

- `.pdf`

## 7. 常见问题

### 天气不可用怎么办

在首页右上角点击天气区域，选择城市或刷新天气。如果仍不可用，通常是网络、定位或天气服务临时不可用。

### 周分析结果不准确怎么办

可以修改原文后重新分析，也可以从「历史」进入旧记录编辑。若启用了本地 LLM，请在「设置」里测试 Ollama 连接。

### 为什么有些日历记录不能编辑

节假日和校历记录是锁定来源，不能在日历页直接编辑。校历可以从「设置」或「历史」重新导入或修改。

### 删除历史会影响其他页面吗

会。删除周分析历史会移除对应的事项和人物关系；删除校历历史会移除对应校历事件。

### PDF 导入后原文件还能移动吗

导入时软件会把 PDF 整理到项目的「资料」目录。为了阅读库稳定，建议通过软件导入后使用软件内的文库入口阅读，不要手动改动已整理文件的位置。

### 换电脑时只复制数据库够吗

如果只关心周分析、日历和设置，复制 `.research_life` 通常足够；如果还要保留 PDF 文库文件，请同时复制「资料」目录。
